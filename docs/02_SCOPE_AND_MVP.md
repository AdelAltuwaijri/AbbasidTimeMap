# Scope and MVP

## In scope for initial product
- Interactive historical map
- Hijri-first timeline
- Gregorian equivalent display
- Year selection and playback
- Historical events displayed geographically
- Event detail drawer/page
- People associated with events
- Places and political states
- Historical sources and confidence labels
- Time-aware political boundaries
- Search across events, people, places, and years
- Basic historical journeys
- Arabic-first interface

## Explicitly out of MVP
- Real-time AI video generation
- Fully simulated historical cities
- Conversational historical-character agents
- Alternate history simulations
- 3D globe
- Mobile native apps
- User-generated public historical claims
- Social features
- Full Abbasid corpus before engine validation

## MVP corpus
Initial curated historical period:
- **132 AH to 170 AH**

Target seed volume:
- 30–50 historical events
- 10–20 people
- 15+ places
- 5–10 military events
- core early-Abbasid political boundaries
- source references for every published event

## MVP success
The MVP is successful when a user can:
1. Open the application.
2. Select a year from the timeline.
3. See the map update to that year.
4. See relevant events and political geography.
5. Open an event.
6. Read a factual summary, causes, consequences, people, places, and sources.
7. Switch between Hijri and dual Hijri/Gregorian date display.

## Scope control
Any feature not explicitly documented in the roadmap is deferred unless added through a decision entry in `21_DECISIONS_LOG.md`.
